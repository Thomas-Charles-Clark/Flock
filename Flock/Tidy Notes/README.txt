Notes are categorised initially as either Broad or Specific.
Further categorisation will be denoted by sub-folders.

/Broad
	- For musings on how I should rebuild core aspects of the solution
	- For keeping permanent record of failures to adhere to patterns

/Specific
	- If it can be readily categorised, it belongs in a subfolder here.
		e.g. /Specific/ErrorHandling
			 /Specific/JQuery
			 /Specific/AJAX

/Tips
	- For storing useful titbits.

All new note files are to be headed, dated, and indexed.

Key paragraphs or topics are to be indexed for cross referencing.

Use http://patorjk.com/software/taag/#p=display&h=3&v=3&f=Doom&t=Layout for headings.
